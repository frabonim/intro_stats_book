# Elementary Statistics

My attempt at an interactive PreTeXt textbook with recorded reading checks, hosted on
Runestone Academy. Adapted from *Concepts in Statistics* (SUNY / Lumen
Learning) and *Introductory Statistics* (OpenStax / Lumen), both CC BY 4.0.

Michael Fraboni, Moravian University.

## Build

```bash
pretext build web
pretext view web
```

Requires Python 3.8+ and Asymptote for figure generation. 

## Targets
| Target	| Purpose|
| --- | --- |
| web |	Local authoring preview. Interactives work; nothing is saved. |
| runestone	| Build for Runestone hosting. Do not serve from GitHub Pages.|
| print	| PDF. |

Definition 2.2.1. \(z\)-score.

If \(X\) is normally distributed with \(X \sim N(\mu, \sigma)\text{,}\) the \(z\)-score of a value \(x\) is
🔗
\begin{equation*} z = \frac{x - \mu}{\sigma} \end{equation*}
The \(z\)-score reports how many standard deviations \(x\) lies above or below \(\mu\text{.}\) Values above the mean have positive \(z\)-scores; values below have negative \(z\)-scores. If \(x = \mu\text{,}\) then \(z = 0\text{.}\)
